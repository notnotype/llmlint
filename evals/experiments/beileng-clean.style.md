# 文体定位
轻快但不碎裂的第三人称贴身叙事。让具体动作、日常物件和身体反应承载信息；在紧张或宏大设定中偶尔使用跨语义的陌生化意象制造记忆点，然后立刻回到人物正在做的事。

# 句式与节奏
- 以完整自然段推进，长短句交替；短句只落在转折、发现、反应或笑点处。
- 允许偶尔把名词、动作和意象跨域搭配，但每段最多保留一个主要陌生化落点。
- 严肃叙述与生活化词汇可以并置制造反差，但不要连续堆网络梗、拟声词或夸张数字。
- 禁止使用“不是……而是……”及其变体；用动作、停顿、反问或“但”完成转折。

# 段落与对话
- 段落承载连续动作和思路，不把每个动作拆成单句。
- 对话独立成段，前后都有动作、物件或环境承接；台词短而有目的。
- 对话不要靠“他用某种语气说”解释情绪，让台词内容和动作露出立场。
- 战斗、追逐和情绪峰值可以加快分段，但不能变成口号清单。

# 视角与情绪
- 默认第三人称贴身限知，只写当前视角人物此刻能感知、理解或猜测的内容。
- 不提前替读者解释世界观答案；新规则先通过试错、询问、触摸、观察或后果逐步出现。
- 情绪先落到呼吸、手指、步伐、视线、衣物、工具或环境，再选择是否点名一次。
- 轻松场景可用自嘲和现实细节收束；真正的损失、恐惧或关系变化必须允许停留，不用笑话强行抹平。

# 修辞与信息
- 比喻、拟人和陌生化只在关键节点使用，优先选择当前场景可触摸的事物。
- 每个自然段至少推进动作、信息、关系或情绪中的一项；笑点之后必须产生行动、选择或新问题。
- 系统、公告、契约等格式化信息短小分批出现，紧跟角色理解和反应，不写成设定说明书。

# 正确示例（原创）
> 门外的警报响了两声，第三声卡在半路，像一只突然想起自己还没吃饭的鸟。
>
> 他把钥匙插进锁孔，停了一下。
>
> “现在撤，还来得及吗？”
>
> 屋里的灯亮了。没人回答，桌上的汤却已经凉透。
>
> 他拔出钥匙，把门推开。先把人找出来，再考虑晚饭。

# 错误示例（原创）
> 叮！系统升级！恭喜宿主获得无敌技能！他兴奋、激动、震撼，心中充满了难以言喻的喜悦！
>
> 他不是害怕，而是紧张；不是犹豫，而是思考；不是走过去，而是冲了过去！
>
> 咚！咚！咚！所有人都沉默了，场面十分尴尬，读者朋友们你们说是不是？

# 核心禁区
- 不复刻任何参考文本的专名、角色、事件、完整桥段或连续原句。
- 不把陌生化搭配变成每句都要出奇的固定表演。
- 不频繁使用同一身体部位、同一拟人词或同一转折模板。
- 不让吐槽抢走行动，不让旁白替角色总结情绪，不让格式化设定压过现场。
- 不连续单句成段，不把正文写成弹幕、段子或规则清单。
- 不为了避开某个词牺牲剧情保真、人物声音、语法清晰度或合理篇幅。

# 生成自检
1. 视角是否始终贴着当前人物，是否泄露了他不知道的信息？
2. 每个关键设定是否通过动作、物件、试错或对话自然出现？
3. 陌生化意象是否少而准，并且服务当前场景？
4. 段落是否承担连续动作，短段是否有明确功能？
5. 对话前后是否有动作承接，是否删掉了多余的语气解释？
6. 情绪是否有身体或行动证据，沉重处是否被允许停留？
7. 笑点、转折或信息落点之后，人物是否继续做出选择？
8. 是否出现了参考来源专名、原句或可识别桥段？
